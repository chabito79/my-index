# My Index

Panel para Claude Code con la lista de todas tus preguntas en la sesión. Tiene un buscador, una lista numerada y un detalle con la pregunta y un extracto de la respuesta. Al hacer clic en una pregunta se copia al portapapeles para pegarla en la búsqueda de la app.

Se actualiza al enviar cada pregunta.

## Instalación

En una sesión de Claude Code, escribe:

```bash
/plugin install my-index --marketplace chabito79/my-index
```

Responde `y` para añadir el marketplace y elige el alcance.

## Limitaciones

No puede saltar a un mensaje concreto de la conversación. La API de mods no lo permite.
